# D5 presentation checklist

The opening guide presents movement, pause, interaction, and later combat/job
preparation in plain language. It is constrained to 560 logical pixels and
wraps four guide cards, so it remains usable at the project's 480 × 640 test
viewport. Essential actions retain labelled buttons and keyboard equivalents;
color is never the only instruction.

Before release, play through the integrated build at the agreed target
viewport and confirm that battle prompts, party/job navigation, save feedback,
loading, and error states remain readable with a keyboard and touch input.
